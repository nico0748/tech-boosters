# hands-on（技術を使いこなし隊）

話題になった技術を実際に使って、使いこなすための実践記事のシリーズです。

ディレクトリと命名のルールは[リポジトリ直下のREADME](../README.md#記事ディレクトリのルール)を参照してください。

## 中身
- [drafts/](drafts/) 下書き（記事1本 = 1ディレクトリ）
  - `no.1-qiita-cli-git-kanri/` Qiita CLIで記事をGit管理する
- [assets/](assets/) シリーズ共通の素材
  - `icon/` シリーズのロゴ
