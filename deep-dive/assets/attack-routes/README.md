- `05_CSRF.png` クロスサイトリクエストフォージェリ
- `06_SSRF.png` サーバーサイドリクエストフォージェリ
- `07_OSコマンドインジェクション.png` OSコマンドインジェクション
- `08_ディレクトリトラバーサル.png` ディレクトリトラバーサル
