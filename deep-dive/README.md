# deep-dive（技術を深ぼり隊）

セキュリティ技術・脆弱性・攻撃を深掘りするシリーズです。XSSやSQLiなどで、内部・低レイヤーで何が起きているかを掘り下げます。

記事の構成は、まず自分が知っていることを書き、そのあとAIとの壁打ちで分からなかった内部動作を明らかにしていく形式です。

## 中身
- `深ぼり隊_記事テンプレート.md` 記事のテンプレート
- `sqli-internals_draft.md` SQLインジェクションの内部動作（下書き）
- `sqli-internals_kabeuchi_draft.md` 同テーマの壁打ち形式版（下書き）
- [attack-routes/](attack-routes/) 攻撃経路図
